# Data advisory — Hrvoje Jerković, PhD

A concise public overview of flexible data advisory, practical demonstrations and preparation for informed technology decisions.

Static HTML, CSS and JavaScript. No build step, external libraries, analytics, forms or stored visitor data.

The engagement-depth selector changes only the example shown on the page. It does not submit a request or create a booking.

Publish with GitHub Pages from the `main` branch and repository root.

## Local preview

Serve this directory with any static HTTP server and open `index.html`. Check desktop and mobile layouts and all three engagement options.

## Content boundaries

This public site contains only the advisor's general professional offer and public portfolio links. Client correspondence, research notes, contact details, internal project documentation and personal messages are maintained separately and are not part of this repository.
